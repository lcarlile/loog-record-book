# LoOG Record Book

A visual record book for the **League of Ordinary Gentlemen** family fantasy football league.
Live site: https://lcarlile.github.io/loog-record-book/

Nine seasons (2017-2025): champions, all-time standings, head-to-head records,
single-week extremes, schedule luck, and season-by-season standings.

## Files

| File | What it is |
|---|---|
| `index.html` | The site. Standalone, self-contained, no build step at runtime. **Generated - do not edit.** |
| `recordbook.html` | Same page as a fragment, for publishing as a Claude Artifact. **Generated.** |
| `template.html` | The actual source: markup, CSS and JS. **Edit this one.** |
| `data.json` | Season records parsed from the record-book spreadsheet. Generated by `parse.js`. |
| `espn.json` | Head-to-head, streaks, weekly extremes and luck, derived from ESPN box scores. |
| `parse.js` | Reads the spreadsheet CSV export, writes `data.json`, and cross-checks the sheet's own totals. |
| `build.js` | Inlines the data into `template.html` and writes both output files. |

## Updating after a season

1. Export the record book spreadsheet to CSV.
2. Point `SRC` at the top of `parse.js` at the new file.
3. Run the build:

   ```sh
   node parse.js   # rebuilds data.json, prints a cross-check of the sheet's totals
   node build.js   # rebuilds index.html and recordbook.html
   ```

4. Commit and push - GitHub Pages redeploys on its own.

`espn.json` holds everything that came from the ESPN league (private league 1197565)
rather than the spreadsheet. Refreshing it needs an authenticated ESPN session; it is
kept as a checked-in file so the build never depends on the network.

## Notes on the data

- Seasons finishing exactly .500 are counted as their own category, not as losses.
- 2024 is the only season with no Biggest Loser recorded.
- The league grew from 8 teams (2017) to 10 (2018-2021) to 12 (2022-present).
